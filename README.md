# NetworkHelper

A beginner-friendly Python tool for basic network troubleshooting.

## Features

- Validate IPv4 addresses
- Test network connectivity using ping
- Handle invalid input and timeouts
- Save test results to a report file
- View report history and connection summaries

## Technologies

- Python
- Git and GitHub
- Windows command-line tools

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

   `python networkhelper.py`

## Learning Goals

This project helped me practice Python functions, exception handling, subprocess commands, file handling, input validation, and Git version control.
